# Sistema de Cadastro de Equipamentos em C

Atividade prática desenvolvida para a disciplina de Algoritmos e pensamento computacional em C.
## Funcionalidades
- Menu interativo com opções de cadastro, listagem e saída.
- Entrada de dados solicitando código de identificação, nome e localização.
- Armazenamento persistente em arquivo de texto (`equipamentos.txt`) utilizando o modo de abertura adequado para preservar os registros.
- Leitura e exibição dos registros em tela utilizando manipulação de arquivos (`fopen`, `fprintf`, `fgets`, `fclose`).

1. Certifique-se de ter um compilador C instalado, ou use um compilador no navegador.
2. Compile o código no terminal:
